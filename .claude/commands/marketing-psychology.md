# Marketing Psychology — 骨董買家心理框架

**Loaded by**: Marketing Agent
**Companion skills**: copywriting.md, social-content.md
**Goal**: 理解骨董市場買家決策模型，設計符合心理的轉化漏斗

> 「賣骨董不是賣商品——是賣傳承、賣身份、賣眼光。」

---

## 三大買家原型

### 1. 投資型買家（30%）
**特徵**：
- 高淨值，視骨董為資產配置
- 重視市場流通性（拍賣行交易記錄、估價）
- 看數據：成交價、年漲幅、稀有度量化指標
- 決策週期：1-3 個月研究 + 諮詢專家

**決策觸發**：
- 來源 / 出處可考（最好有拍賣行紀錄、博物館館藏對照）
- 同類成交價趨勢上揚
- 專業鑑定書 / 證書齊備
- 流通性指標：「過去 5 年同類在蘇富比成交 N 件」

**對應內容策略**：
- 數據式介紹（市場走勢、稀有度分位）
- 拍賣行對照（成交價區間）
- 鑑定書出示

### 2. 收藏型買家（45%）
**特徵**：
- 中產到高淨值，深度文化興趣
- 累積系列性收藏（如專收清代官窯、專收銅爐）
- 重視「故事」與「品味」
- 決策週期：1-4 週深度互動

**決策觸發**：
- 與既有收藏的呼應（「您現有的 OO，本件正可補齊...」）
- 故事性（前藏家、流轉脈絡、典故出處）
- 品味認同（賣家的眼光被認可）
- 賞玩細節（包漿、胎骨、款識細看）

**對應內容策略**：
- 鑑賞文章（教育性，建立信任）
- 流轉故事（不誇大但帶情感）
- 系列邀請（「同件出處的另一件...」）

### 3. 文化型買家（25%）
**特徵**：
- 學者 / 文人 / 藝術家
- 預算有限但眼力深
- 看重學術性、歷史價值
- 決策週期：6 週以上反覆觀察

**決策觸發**：
- 學術引用（《陶說》《飲流齋說瓷》等）
- 與博物館 / 機構藏品的學術對照
- 修復狀態誠實揭露
- 賣家本人專業度展現

**對應內容策略**：
- 學術文章（朝代源流、製作工藝）
- 引典深度
- 誠實的瑕疵說明（反而強化信任）

## 信任建立序列（核心 funnel）

骨董市場「**信任 > 衝動**」。轉化路徑必須拉長：

```
[認識]    社群曝光（IG / FB / 搜尋）
   ↓ 1-2 週
[興趣]    深度內容（鑑賞文章、典故）
   ↓ 1-3 週
[信任]    專業展現（拍賣行對照、學術引用）
   ↓ 1-4 週
[渴望]    特定藏品打動（與買家既有收藏呼應）
   ↓ 1-2 週
[行動]    邀請看件（實鑑、面談）
   ↓ 當下到當週
[成交]    實體店確認（看件、議價、簽證書）
```

**整個 funnel 從認識到成交：6-12 週是常態，3 個月以上不奇怪**。

---

## ENFORCE — 反 patterns（散戶廣告手段不適用）

骨董客群跟一般電商完全相反，這些手段**禁止**使用：

- ❌ **限時搶購** — 骨董不是消費品，買家不接受倒數計時
- ❌ **稀缺操弄**（「最後一件」） — 骨董本質就稀缺，誇大反而 cheap
- ❌ **明星代言** — 不適合機構品牌
- ❌ **直接打折** — 骨董無「原價」概念，打折暗示「不值」
- ❌ **「不買後悔」威脅式行銷** — 跟典雅品牌格相違
- ❌ **盲盒 / 抽獎** — 完全錯位

## ALLOWED — 高效率轉化機制

### 1. **權威背書**
- 拍賣行記錄（蘇富比、佳士得、嘉德、保利）
- 博物館同類館藏對照
- 學術文獻引用
- 專業鑑定師認證

### 2. **故事化器物**
- 前藏家流轉
- 製作工坊的歷史
- 朝代背景的政治 / 文化脈絡
- **不誇大**，事實為主

### 3. **教育型行銷**
- 鑑賞知識文章（讓買家覺得自己變有眼光）
- 鑑定要點分享（不藏私）
- 修復過程揭露（透明）

### 4. **社群歸屬感**
- 賞鑑會 / 看展活動（吸引到實體店）
- LINE 私訊深度諮詢
- 跨年度的客戶關係

### 5. **實體店體驗**
- 線上看不到、線下才能感受的細節（包漿、手感、釉色）
- 賞鑑空間設計（仿博物館展示）
- 親自接待 / 解說（不是業務推銷）

## 引流到實體店的設計（AP 核心目標）

吉寶軒不做線上交易，所有轉化都導向**實體店看展與預約**。CTA 設計原則：

- **NEVER**：「立即購買」「下單」「加入購物車」
- **PREFER**：「敬邀蒞店實鑑」「歡迎電洽預約」「同件本軒展廳即可賞鑑」
- 提供：地址 / 電話 / LINE 預約連結 / Google Maps 導航
- 預約系統：必填「希望看件」「興趣朝代」「方便時段」

## Pre-Flight Checklist（Marketing Agent 設計 campaign 前自查）

- [ ] 識別目標買家原型（投資 / 收藏 / 文化）
- [ ] funnel 階段對了嗎？（認識/興趣/信任/渴望/行動 各階段對應內容類型不同）
- [ ] 沒有用「限時」「最後」「搶購」這類散戶手段
- [ ] CTA 是「邀請看展」而非「立即購買」
- [ ] 信任建立元素夠（拍賣行 / 博物館 / 學術 對照）

## 量化評估（每月 retro）

| 指標 | 目標 |
|---|---|
| 社群觸及 | 月增 5-10% |
| LINE 預約看件次數 | 月 ≥ 8 次 |
| 實體店訪客 | 月 ≥ 30 人 |
| 看件 → 成交率 | 15-25%（骨董市場常態） |
| 平均成交週期 | 6-12 週 |

## When to escalate to Opus

- 重大策略決定（例：要不要拓展年輕收藏家市場）
- 危機事件（例：藏品真偽爭議公開回應）
- 跨機構合作（例：與博物館聯展）
