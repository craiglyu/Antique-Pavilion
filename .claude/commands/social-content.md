# Social Content Strategy — 吉寶軒社群內容策略

**Loaded by**: Marketing Agent
**Companion skills**: copywriting.md（文案規則）、marketing-psychology.md（買家心理）
**Goal**: 跨平台社群內容差異化策略，引流到實體店看展與預約

> 「展示器物以視覺為先，傳達神韻以文字為輔。」

---

## 平台定位（差異化原則）

### Instagram — 視覺優先
- **內容主軸**：器物近照 / 細節微觀 / 展廳氛圍 / 修復過程
- **構圖**：方形 1:1（feed）或豎版 9:16（reels / story）
- **後製**：低飽和度（< 70%），加金色細點綴，禁用 HDR / 鮮豔濾鏡
- **caption**：80-150 字，一句吸睛 + 教育性內容
- **hashtag**：限 5-8 個，混中英文 #清代瓷器 #ChinesePorcelain #Antique
- **頻率**：每週 3-4 則 feed + 每日 1 則 story

### LINE 官方帳號 — 深度資訊
- **內容主軸**：新藏品上架公告 / 鑑賞文章 / 看展邀請 / 收藏指南
- **互動**：1-on-1 私訊諮詢、預約看件
- **長度**：200-400 字 + 1-3 張高清圖
- **頻率**：每週 1-2 則群發

### Facebook — 社群討論
- **內容主軸**：典故文章 / 鑑藏知識 / 業界動態 / 展覽分享
- **長度**：300-600 字，可附 3-5 圖
- **互動**：留言提問、分享 / 評論
- **頻率**：每週 2-3 則

### 網站文章（Publish/）— 長知識
- **內容主軸**：朝代專題 / 流派源流 / 鑑賞指南
- **長度**：800-2000 字
- **SEO 關鍵字**：長尾詞為主（「明代銅爐辨偽」「乾隆官窯特徵」）
- **頻率**：每月 4-8 篇

## 內容類別（按比例分配）

理想週社群內容比：

| 類別 | 比例 | 範例 | 目的 |
|---|---|---|---|
| **新藏品介紹** | 30% | 「清光緒銅胎掐絲琺瑯香爐」 | 銷售引流 |
| **鑑賞知識** | 30% | 「如何辨識真偽明宣德爐」 | 信任建立 + SEO |
| **典故文化** | 20% | 「文房四寶之外的第五寶——香爐」 | 品牌深度 |
| **展廳活動** | 15% | 「本月展出主題：清三代御製」 | 引流到實體店 |
| **修復 / 保養** | 5% | 「銅器包漿養護要點」 | 專業展示 |

---

## ENFORCE — 禁止 patterns

- **NO** 跟風 meme（不適合品牌調性）
- **NO** 限時搶購倒數計時
- **NO** 「按讚抽獎」這類流量手段（傷害品牌）
- **NO** 競標 / 拍賣風格（吉寶軒是賞鑑，不是拍賣）
- **NO** 直接掛價格（價格只在 LINE 私訊或店內公告）

---

## ALLOWED — 推薦 patterns

- **引用蘇富比 / 佳士得對照**（「同類器於 2019 年蘇富比香港春拍...」）
- **故宮 / 博物館典藏對照**（「故宮博物院藏有近例」）
- **學術引用**（「《陶說》《飲流齋說瓷》中提及...」）
- **修復 before/after**（透明展示工藝）
- **館內展廳影片**（5-15 秒，純視覺，配古典樂器音樂）

## Hashtag Strategy

### 中文 hashtag（基本款）
- 朝代：#清代瓷器 #明代銅爐 #宋代汝窯
- 品類：#粉彩 #青花 #銅胎掐絲琺瑯
- 通用：#骨董 #古玩 #藝術品

### 英文 hashtag（國際曝光）
- `#ChinesePorcelain` `#ChineseAntique` `#AntiqueGallery`
- `#QingDynasty` `#MingDynasty`
- `#Sothebys` `#Christies`（蹭流量但不過量）

### 品牌專屬
- `#吉寶軒` `#JibaoXuan` `#吉寶軒賞鑑`

**原則**：每則貼文 5-8 個 hashtag。混中英、混朝代/品類/品牌，不堆 30 個。

## Posting Cadence（推薦排程）

| 時段 | 平台 | 內容 |
|---|---|---|
| 週一上午 | IG feed | 新藏品介紹 |
| 週三下午 | FB | 鑑賞知識長文 |
| 週四晚 | IG story | 展廳氛圍 |
| 週五晚 | LINE 群發 | 週末看展邀請 |
| 週日 | IG reel | 細節微觀 / 修復過程 |

## Pre-Flight Checklist（Marketing Agent 出稿前）

- [ ] 平台對了嗎？（IG ≠ FB ≠ LINE 各自有差異化內容）
- [ ] 內容類別比例週均衡（不全是新藏品）
- [ ] 圖片飽和度 < 70%
- [ ] 中英 hashtag 5-8 個
- [ ] 沒有「按讚抽獎」「限時」「倒數」
- [ ] 文案先過 copywriting.md 自查
- [ ] 心理觸發點先過 marketing-psychology.md 對照
